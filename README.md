# Problem Solving and Testing Using Java

## Overview

This repository contains the laboratory exercises and programming tasks completed as part of the **Problem Solving and Testing Using Java** course at **Veltech University**.

The repository focuses on developing problem-solving skills through Java programming and applying systematic approaches to algorithm design, implementation, testing, debugging, and validation.

## Course Information

* **University:** Veltech University
* **Course:** Problem Solving and Testing Using Java
* **Programming Language:** Java
* **Course Type:** Laboratory
* **Purpose:** Academic and Practical Programming Exercises

## Key Areas

### Problem Solving

The programming exercises focus on analyzing problems, developing appropriate algorithms, implementing solutions in Java, and evaluating their correctness and efficiency.

### Java Programming

The tasks provide practical experience with Java syntax, object-oriented programming, collections, functional programming features, and standard Java APIs.

### Testing

Testing exercises focus on validating program behavior using appropriate test cases, identifying edge cases, detecting errors, and verifying that implementations produce the expected results.

### Debugging

Programs are analyzed and refined to identify logical, syntactical, and runtime errors while improving code reliability and maintainability.

## Requirements

A compatible Java Development Kit (JDK) is required to compile and execute the programs.

Verify the installation using:

```bash
java -version
javac -version
```

Java 8 or later may be used depending on the requirements of individual exercises.

## Running a Program

Clone the repository:

```bash
git clone <YOUR-REPOSITORY-URL>
```

Navigate to the repository:

```bash
cd Problem-Solving-and-Testing-Using-Java
```

Compile a Java program:

```bash
javac Solution.java
```

Run the compiled program:

```bash
java Solution
```

For programs containing packages, use the appropriate package structure and compilation commands.
